# 傅里叶实验室

交互式傅里叶级数与离散傅里叶变换演示。纯 HTML、CSS 和 JavaScript，全部计算在浏览器本地完成，无外部依赖。

[打开在线演示](https://sunrise690.github.io/qwer/)

## 交互功能

- 波形合成：方波、锯齿波、三角波与 25% 占空比脉冲波；调节谐波项数、基频和播放速度。
- 旋转圆绘图：心形、五角星、猫咪轮廓及鼠标或触屏手绘；轮廓闭合后均匀采样 256 点，进行 DFT 并重绘。
- 展示幅度谱、单项谐波和重建均方根误差。
- 暂停、拖动周期进度、全屏演示及导出当前画面为 PNG。

下载 `index.html` 后，双击即可离线打开。动画支持空格键暂停或继续；设置“减少动态效果”时默认暂停。

## 数学约定

波形模式使用周期信号的傅里叶级数解析系数；绘图模式使用复数采样 `z = x + iy` 的 DFT，并保留直流分量。绘图坐标纵轴向下，正负频率沿相反方向旋转。

这里展示的傅里叶级数、DFT 和重建与连续傅里叶变换相联系，但并非同一个运算。手绘首尾自动连接，闭合段同样参与计算。

网站入口为仓库根目录的 `index.html`，通过 GitHub Pages 静态部署。
